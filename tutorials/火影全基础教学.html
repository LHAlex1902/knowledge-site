核心规则 可直接拿去用的部分

以下从弹幕中提炼，按可靠性分级。标「观众补充」的属于弹幕纠正或补全，非 UP 主原话。

保护机制三色 观众补充

  • 白色保护：落地后弹起一次，坠落速度正常
  • 黄色保护：不弹地，坠落速度加快
  • 红色保护：坠落速度进一步加快，站立所需时间减少
  • 规律总结：颜色越往后，越不容易接续连招，但免伤越高

平推的准确含义 观众纠正

  • 不是一种「技巧」，而是状态描述
  • 判定条件：Z 轴高度为 0 时受到攻击
  • 此时造成的伤害统一算作平推伤害

「一技能」位置不固定 观众补充

  • 部分忍者的一技能位置实际是平 A
  • 官方爆料与技能描述标注位曾与实战不符
  • 当前版本一技能对应界面下方那个按钮
  • 属历史遗留问题，不能按统一位置套用

通灵数量 易被误导

  • 正常对局：一局 3 个通灵
  • 视频中「10 通灵」是彩蛋 / 卡 bug，不是常规玩法
  • 地狱道等特殊机制需单独判断

大招扣豆规则 观众补充

  • 扣四豆 → 奥义大招
  • 扣二豆 / 一豆 → 小奥义
  • 能出奥义图但不扣四豆的情况存在（如桀骜阿斯玛扣两豆）
  • 判断依据看扣豆数，不看是否有奥义图

X / Y 轴走位 视频讲解

  • 把场地当平面直角坐标系
  • 左右移动 = X 轴
  • 上下移动 = Y 轴
  • 用坐标理解走位，比凭感觉更容易复现

硬体 vs 金刚体 观众补充

  • 硬体：可被部分特殊强化普攻、抓取普攻打断
  • 金刚体：抓取也抓不到，级别更高
  • 视频中「钢体」的说法不准确

抓取与保护值 版本相关

  • 典型例：天道佩恩一技能抓取可破霸体，2.5 秒内伤害不计保护值
  • 但这是旧版本表现
  • 现版本抓取也会计入保护
  • 老佩恩不计入的真实原因是敌人处于站立受击状态

减伤来源 观众补充

  • 晓蛇·罗生门：命中后减伤
  • 半藏 + 山椒鱼：减攻击
  • 带乌龟：减伤 50%
  • 油女取根相关机制另算

火遁灼烧不是通用属性 观众补充

  • 佐助·天照：有灼烧
  • 晓鼬·天照：没有灼烧
  • 不能按「火遁」标签一刀切

遁地分两类 观众补充

  • 非无敌遁地（如新春兜）：可被打到
  • 无敌遁地（如创生迪）：判定不同
  • 混为一谈会导致应对方式出错

常见误区 看视频时最容易记错的地方

以下四处是弹幕里被多人纠正的点，属于「照视频原话记会出错」的内容。

视频说：钢体
准确说法是 金刚体。硬体与金刚体是两级，能打断的条件完全不同。
视频说：一局能有 10 个通灵
那是彩蛋或卡 bug。正常对局只有 3 个通灵，照 10 个去规划节奏会直接崩。
视频说：平推是一种技巧
平推是状态：Z 轴高度为 0 时受击即算平推伤害。它不是一个可以主动「练」的手法。
视频说：抓取不计入保护值
旧版本成立，现版本抓取也计入保护。老佩恩的例子是因为敌人处于站立受击状态，不是抓取特权。
