Shell 脚本 = 把一串命令写进 .sh 文件，加变量/判断/循环，让 Shell 一次性执行。第一行 #!/bin/bash 指定解释器。

基础骨架

hello.sh变量 · 条件 · 循环
#!/bin/bash
# 注释以 # 开头
name="ADB"
echo "开始处理 $name"

if [ -f log.txt ]; then
    echo "文件存在"
    grep ERROR log.txt
else
    echo "文件不存在"
fi

for i in 1 2 3; do
    echo "第 $i 次"
done
易错点：变量赋值 name="x" 等号两边不能有空格；[ ] 内两边必须有空格。

日志统计实战

#!/bin/bash
# 统计日志中出现最多的前 10 个报错
grep -iE 'error|exception|crash' app.log \
  | sort \
  | uniq -c \
  | sort -rn \
  | head -10

抓崩溃日志

capture_crash.sh清缓冲→抓→过滤→存文件
#!/bin/bash
LOGFILE="crash_$(date +%Y%m%d_%H%M%S).log"
echo "=== 开始抓取崩溃日志 ==="
adb logcat -c
echo "请操作 App 复现，30 秒后导出..."
sleep 30
adb logcat -d | grep -A20 'FATAL EXCEPTION' > "$LOGFILE"
echo "已保存到 $LOGFILE，共 $(wc -l < "$LOGFILE") 行"
ADB（安卓调试桥）是电脑与安卓设备的桥梁：装包、抓日志、传文件、模拟操作。下面按场景分类，点击复制。

设备管理

devices查看/连接设备
adb devices                          # 列出设备
adb devices -l                       # 详细信息
adb connect 192.168.1.100:5555       # 无线连接
adb -s <序列号> shell                # 指定设备
adb kill-server && adb start-server  # 重启服务
adb reboot                           # 重启设备

应用管理

install / start安装·卸载·启动
adb install app.apk                  # 安装
adb install -r app.apk               # 覆盖安装保留数据
adb uninstall com.example.app        # 卸载
adb shell pm list packages | grep game  # 查包名
adb shell am start -n 包名/.MainActivity  # 启动
adb shell am force-stop 包名         # 强制停止
adb shell pm clear 包名              # 清除数据

文件传输

pull / push方向相反
adb pull /sdcard/file.txt ./         # 设备 → 电脑
adb push ./config.json /sdcard/      # 电脑 → 设备
adb shell run-as 包名 ls files/      # 看私有目录(debug包)

日志抓取（核心）

logcat抓日志·定位崩溃
adb logcat                           # 实时全部
adb logcat *:E                       # 只看 Error 及以上
adb logcat -s MyTag                  # 按 Tag 过滤
adb logcat | grep -iE 'error|crash'  # 关键字
adb logcat -c                        # 清缓冲
adb logcat -d > log.txt              # 导出
adb logcat | grep -A20 'FATAL EXCEPTION'  # 抓崩溃
adb logcat --pid=<pid>              # 指定进程

屏幕与模拟操作

screencap / input截图·录屏·点击
adb exec-out screencap -p > screen.png   # 截图到电脑
adb shell screenrecord /sdcard/demo.mp4  # 录屏
adb shell input tap 500 800            # 模拟点击
adb shell input swipe 300 1000 300 300 300  # 滑动
adb shell input keyevent 26            # 电源键
adb reverse tcp:8888 tcp:8888          # 端口转发(辅助抓包)

mitmproxy 记录请求

save_requests.py运行：mitmdump -s save_requests.py
import json
from datetime import datetime
from mitmproxy import http

def response(flow: http.HTTPFlow) -> None:
    record = {
        'time': datetime.now().isoformat(),
        'method': flow.request.method,
        'url': flow.request.pretty_url,
        'status': flow.response.status_code,
    }
    with open('requests.log', 'a', encoding='utf-8') as f:
        f.write(json.dumps(record, ensure_ascii=False) + '\n')

分析日志 Top 报错

analyze_log.py统计错误分布
import re
from collections import Counter
from pathlib import Path

ERROR_PATTERN = re.compile(r'(ERROR|Exception|CRASH)', re.I)

def analyze(top_n: int = 10) -> None:
    path = Path('app_log.txt')
    counter: Counter[str] = Counter()
    for line in path.read_text(encoding='utf-8', errors='ignore').splitlines():
        if ERROR_PATTERN.search(line):
            counter[line.strip()[:120]] += 1
    for msg, cnt in counter.most_common(top_n):
        print(f'[{cnt:>4}] {msg}')

if __name__ == '__main__':
    analyze()

FiddlerScript 基于 JScript.NET，菜单 Rules → Customize Rules 打开 CustomRules.js。两个核心钩子：OnBeforeRequest（改请求）、OnBeforeResponse（改响应）。

给请求加自定义头

CustomRules.js加测试环境标识
static function OnBeforeRequest(oSession: Session) {
    oSession["RequestHeaders"]["X-Test-Env"] = "qa";
}

Mock 固定响应

CustomRules.js拦截某接口返回
static function OnBeforeResponse(oSession: Session) {
    if (oSession.uriContains("api.example.com/user")) {
        oSession.SetResponse(200,
            "{\"code\":0,\"name\":\"mock用户\"}",
            "application/json");
    }
}

记录所有请求

CustomRules.js写日志便于复盘
static function OnBeforeRequest(oSession: Session) {
    FiddlerApplication.Log.WriteString(
        oSession.method + " " + oSession.fullUrl + "\n");
}
