1 📖 requests 是什么？

requests 是 Python 最流行的 HTTP 库，比内置的 urllib 简洁太多。它让你用几行代码就能发送 HTTP 请求、处理响应——是接口测试、爬虫、自动化脚本的基石。

💡 一句话： requests = 用 Python 发 HTTP 请求。GET、POST、PUT、DELETE 全支持，语法极其简洁。
对比urllib（内置）requests
GET 请求urllib.request.urlopen(url)requests.get(url)
POST JSON需手动序列化 + 设 Content-Typerequests.post(url, json=data)
响应解析手动 .read().decode()resp.json() 一行搞定
Cookie 保持需手动管理requests.Session() 自动保持
超时控制需手动设置 sockettimeout=5 一个参数

HTTP 方法速览

方法含义典型场景
GET获取数据查询列表、获取详情
POST创建数据登录、提交表单、新增记录
PUT完整更新替换整个资源
PATCH部分更新只改某个字段
DELETE删除数据删除记录

3 🌐 GET 请求 — 获取数据

3.1 最简单的 GET

Python基础 GET
import requests

# 向 httpbin.org 发 GET 请求（一个测试用的网站）
resp = requests.get("https://httpbin.org/get")

print(resp.status_code)  # 200
print(resp.text)         # 响应文本
print(resp.json())       # 解析为字典

3.2 带查询参数的 GET

Python带参数的 GET
# ✅ 正确方式：用 params 参数（自动 URL 编码）
params = {"q": "python", "page": 1}
resp = requests.get("https://httpbin.org/get", params=params)

print(resp.url)
# https://httpbin.org/get?q=python&page=1

# ❌ 错误方式：手动拼接 URL（容易出错）
# resp = requests.get("https://httpbin.org/get?q=python&page=1")
⚠️ 永远用 params 参数传查询字符串，不要手动拼 URL。requests 会自动处理 URL 编码（中文、特殊字符等）。

4 📤 POST 请求 — 提交数据

POST 是最常用的写操作，有三种传数据方式：

PythonPOST JSON
# ✅ 方式1：json= 参数（推荐，自动设 Content-Type: application/json）
data = {"username": "testuser", "password": "123456"}
resp = requests.post("https://httpbin.org/post", json=data)

print(resp.json()["json"])
# {'username': 'testuser', 'password': '123456'}
PythonPOST 表单
# 方式2：data= 参数（form-urlencoded 或 multipart）
data = {"username": "testuser", "password": "123456"}
resp = requests.post("https://httpbin.org/post", data=data)

# 传文件（multipart/form-data）
files = {"file": ("report.xlsx", open("report.xlsx", "rb"))}
resp = requests.post("https://httpbin.org/post", files=files)
PythonPOST 原始 body
# 方式3：data= 传字符串（需手动设 Content-Type）
import json
body = json.dumps({"key": "value"})
resp = requests.post(
    "https://httpbin.org/post",
    data=body,
    headers={"Content-Type": "application/json"}
)
🔑 三种方式对比：
方式参数Content-Type场景
JSONjson={...}自动设 application/jsonAPI 接口（最常用）
表单data={...}自动设 application/x-www-form-urlencoded传统表单提交
文件files={...}自动设 multipart/form-data文件上传

PUT / PATCH / DELETE

PythonPUT / PATCH / DELETE
# PUT — 完整更新资源
resp = requests.put("https://httpbin.org/put", json={"name": "新名字"})

# PATCH — 部分更新资源
resp = requests.patch("https://httpbin.org/patch", json={"status": "done"})

# DELETE — 删除资源
resp = requests.delete("https://httpbin.org/delete")

Python自定义请求头
# 方式1：headers 参数
headers = {
    "Authorization": "Bearer eyJhbGciOiJIUzI1NiIs...",
    "Content-Type": "application/json",
    "User-Agent": "MyTestBot/1.0",
    "X-Custom-Header": "custom-value",
}
resp = requests.get("https://httpbin.org/headers", headers=headers)
print(resp.json()["headers"])

# 方式2：修改默认头（全局生效）
from requests.adapters import HTTPAdapter

⚠️ 常见场景：
  • 认证：Authorization: Bearer <token>
  • API Key：X-API-Key: <key>
  • 模拟浏览器：User-Agent: Mozilla/5.0 ...
  • 指定内容类型：Content-Type: application/json

7 📎 文件上传

Python上传单个/多个文件
# 上传单个文件
with open("screenshot.png", "rb") as f:
    resp = requests.post(
        "https://httpbin.org/post",
        files={"file": ("screenshot.png", f, "image/png")}
    )

# 上传多个文件
files = [
    ("files", ("a.png", open("a.png", "rb"))),
    ("files", ("b.png", open("b.png", "rb"))),
]
resp = requests.post("https://httpbin.org/post", files=files)

# 混合上传（文件 + 普通字段）
data = {"description": "测试截图"}
files = {"file": open("screenshot.png", "rb")}
resp = requests.post("https://httpbin.org/post", data=data, files=files)
⚠️ 注意： 文件字段用 files=，普通文本字段用 data=。不要混在一起用 json=。

8 🍪 Session — 保持会话状态

Session 是 requests 中最重要的高级功能。它能自动保持 Cookie、共享请求头，是模拟登录场景的必备技能。

PythonSession 模拟登录
import requests

session = requests.Session()

# ① 设置公共请求头（后续所有请求自动带上）
session.headers.update({
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"
})

# ② 登录（Cookie 自动保存到 session）
login_data = {"username": "testuser", "password": "123456"}
resp = session.post("https://example.com/login", data=login_data)
print(f"登录状态: {resp.status_code}")

# ③ 后续请求自动携带登录 Cookie，无需手动处理
resp = session.get("https://example.com/profile")
print(f"用户信息: {resp.text[:100]}")

# ④ 关闭 session（释放连接）
session.close()
💡 Session 的三大好处：
  1. Cookie 自动保持 — 登录后续请求无需手动传 Cookie
  2. 请求头共享 — session.headers.update() 一次设置，全局生效
  3. 连接池复用 — 多次请求复用 TCP 连接，性能更好

9 📥 响应处理 — 从 Response 对象中提取数据

PythonResponse 对象常用属性和方法
resp = requests.get("https://httpbin.org/get")

# ── 状态码 ──
print(resp.status_code)       # 200
print(resp.ok)                # True（2xx 为 True）

# ── 响应内容 ──
print(resp.text)              # 文本内容（str）
print(resp.content)           # 二进制内容（bytes）
print(resp.json())            # 解析 JSON → dict/list
print(resp.encoding)          # 编码，如 'utf-8'

# ── 响应头 ──
print(resp.headers)           # 响应头字典
print(resp.headers["Content-Type"])  # application/json

# ── 请求信息（调试用）──
print(resp.request.url)       # 实际请求的 URL
print(resp.request.headers)   # 实际发送的请求头
print(resp.request.body)      # 实际发送的请求体

# ── 耗时 ──
print(resp.elapsed.total_seconds())  # 请求耗时（秒）

# ── 历史重定向 ──
print(resp.history)           # 重定向历史列表
print(resp.url)               # 最终 URL（重定向后）
📊 常用状态码：
状态码含义测试中的处理
200成功正常校验响应体
201创建成功POST 返回新资源
400请求参数错误校验错误提示
401未认证Token 过期/无效
403无权限权限校验
404资源不存在边界测试
500服务器内部错误异常场景

10 ⏱️ 超时设置与异常处理

10.1 超时设置

Python超时设置
# 方式1：连接超时（秒）
resp = requests.get("https://api.example.com", timeout=5)

# 方式2：连接超时 + 读取超时（推荐）
resp = requests.get("https://api.example.com", timeout=(3.05, 10))
# 连接超时 3.05s，读取超时 10s

# ⚠️ 永远不要不设 timeout！网络问题会导致程序永久卡死
⚠️ 铁律：每个 requests 调用都必须带 timeout 参数。 不设超时的请求一旦遇到网络问题，程序会永久阻塞。

10.2 异常处理

Python异常处理最佳实践
import requests

try:
    resp = requests.get("https://api.example.com/data", timeout=10)

    # 检查 HTTP 状态码（非 2xx 会抛出 HTTPError）
    resp.raise_for_status()

    # 解析 JSON（如果格式不对会抛出 JSONDecodeError）
    data = resp.json()
    print(data)

except requests.exceptions.ConnectionError:
    print("❌ 连接失败：网络不通或地址错误")

except requests.exceptions.Timeout:
    print("⏰ 请求超时")

except requests.exceptions.HTTPError as e:
    print(f"⚠️ HTTP 错误：{e}")  # 如 404、500

except requests.exceptions.RequestException as e:
    print(f"🔴 请求异常：{e}")  # 所有异常的基类
💡 异常层次（从上到下越来越通用）：
ConnectionError → 网络不通
Timeout → 超时
HTTPError → 状态码非 2xx（需调 raise_for_status 触发）
RequestException → 所有请求异常的基类

11 🛠️ 实战案例

案例 1：完整的登录 + 鉴权流程
Pythontest_auth.py
import requests
import pytest

BASE_URL = "https://api.example.com"

class TestAuth:
    """认证模块测试"""

    def test_login_success(self):
        """正常登录"""
        resp = requests.post(
            f"{BASE_URL}/api/login",
            json={"username": "admin", "password": "123456"},
            timeout=10
        )
        assert resp.status_code == 200
        data = resp.json()
        assert "token" in data
        assert len(data["token"]) > 0

    def test_login_wrong_password(self):
        """密码错误"""
        resp = requests.post(
            f"{BASE_URL}/api/login",
            json={"username": "admin", "password": "wrong"},
            timeout=10
        )
        assert resp.status_code == 401

    def test_access_protected_resource(self):
        """用 token 访问受保护资源"""
        # 先登录
        login_resp = requests.post(
            f"{BASE_URL}/api/login",
            json={"username": "admin", "password": "123456"},
            timeout=10
        )
        token = login_resp.json()["token"]

        # 用 token 访问
        resp = requests.get(
            f"{BASE_URL}/api/profile",
            headers={"Authorization": f"Bearer {token}"},
            timeout=10
        )
        assert resp.status_code == 200
        assert resp.json()["username"] == "admin"
案例 2：分页数据拉取（含重试机制）
Pythontest_pagination.py
import requests
import time

def fetch_all_pages(base_url, max_retries=3):
    """拉取所有分页数据（带重试）"""
    all_items = []
    page = 1

    while True:
        for attempt in range(max_retries):
            try:
                resp = requests.get(
                    f"{base_url}/api/items",
                    params={"page": page, "size": 100},
                    timeout=(3, 10)
                )
                resp.raise_for_status()
                break  # 成功则跳出重试循环
            except requests.exceptions.RequestException as e:
                if attempt == max_retries - 1:
                    raise  # 最后一次仍失败，抛出异常
                time.sleep(2 ** attempt)  # 指数退避：1s, 2s, 4s

        data = resp.json()
        items = data.get("items", [])
        all_items.extend(items)

        # 判断是否还有下一页
        if len(items) < 100 or page >= data.get("total_pages", 1):
            break
        page += 1

    return all_items

# 使用
items = fetch_all_pages("https://api.example.com")
print(f"共拉取 {len(items)} 条数据")

Pythonconftest.py
"""共享 fixture"""
import pytest
import requests

BASE_URL = "https://api.example.com"

@pytest.fixture(scope="session")
def auth_token():
    """会话级：整个测试会话只登录一次"""
    resp = requests.post(
        f"{BASE_URL}/api/login",
        json={"username": "testuser", "password": "123456"},
        timeout=10
    )
    resp.raise_for_status()
    return resp.json()["token"]

@pytest.fixture
def headers(auth_token):
    """每个测试函数获取带 token 的请求头"""
    return {"Authorization": f"Bearer {auth_token}"}

@pytest.fixture
def api(headers):
    """封装好的 requests 调用（自动带 token 和 timeout）"""
    def _get(path, **kwargs):
        kwargs.setdefault("timeout", 10)
        return requests.get(f"{BASE_URL}{path}", headers=headers, **kwargs)
    def _post(path, json_data=None, **kwargs):
        kwargs.setdefault("timeout", 10)
        return requests.post(f"{BASE_URL}{path}", json=json_data, headers=headers, **kwargs)
    return {"get": _get, "post": _post}
